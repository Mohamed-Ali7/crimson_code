
# Crimson Code

## 📌 Project Overview

**Crimson Code** is a modern web platform aimed at delivering high-quality, trustworthy technical content through community-driven posts and discussions. The project is split into two main parts:

- **Backend** — A RESTful API built with Spring Boot to handle authentication, content management, and business logic.
- **Frontend** — A responsive web client built with plain HTML, CSS, JavaScript, and jQuery to provide a user-friendly interface.
